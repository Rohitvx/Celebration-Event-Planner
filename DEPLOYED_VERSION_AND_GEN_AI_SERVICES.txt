2. GENERATIVE AI SERVICES UTILIZED & WHERE THEY ARE UTILIZED
================================================================================

A. PRIMARY GEN AI MODEL & ARCHITECTURE
--------------------------------------------------------------------------------
1. Google Gemini Generative AI (gemini-1.5-flash):
   - Endpoint: https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent
   - Integration: Direct REST API integration supporting structured JSON output
     schema via `generationConfig: { responseMimeType: 'application/json' }`.
   - Security: Configurable via UI settings (Stored securely in browser localStorage,
     never logged or exposed) or via environment variable VITE_GEMINI_API_KEY.

2. Dual-Engine Fallback Architecture (src/services/aiService.ts):
   - To guarantee zero downtime, offline capability, and instant sub-400ms responses,
     CelebrationAI features a dual-engine design.
   - When no API key is supplied or if network limits are reached, the system
     seamlessly shifts to an internal smart generation engine calibrated to
     Indian celebration norms, regional cuisines, and realistic market rates.

B. WHERE GENERATIVE AI IS UTILIZED IN THE APPLICATION
--------------------------------------------------------------------------------
Gen AI is actively utilized across five (5) critical modules of the project:

1. End-to-End Event Plan Synthesis (src/services/aiService.ts -> generateEventPlan)
   - Where: Invoked directly from the Event Creation Wizard (src/components/wizard/EventWizard.tsx).
   - What it does: Takes user constraints (event type, guest count, INR budget,
     location, theme, decor style, food preference, and special requirements) and
     generates a complete structured master plan containing:
     * Concept Title & Narrative Vibe Summary
     * Harmonious 4-color palette with hex codes
     * Tailored catering recommendations (e.g., Live Chaat, Awadhi Dum Biryani,
       or Cocktail Sliders based on selected dietary preferences)
     * Curated entertainment and live performance ideas
     * Guest experience touchpoints (e.g., 360-degree slow-mo video booths,
       QR-code memory galleries)
     * Risk mitigation contingencies (weather, sound permits, vendor backups)
     * Master day-of hourly run-down schedule

2. Context-Aware Conversational Event Assistant (src/services/aiService.ts -> chatWithAssistant)
   - Where: Accessible directly on the main Dashboard (src/components/dashboard/DashboardOverview.tsx).
   - What it does: An interactive conversational agent that possesses full contextual
     awareness of the currently active event's title, guest count, location, venue type,
     and total INR budget. Users can ask questions like:
     * "How can I cut 15% from my budget without ruining guest experience?"
     * "What decor theme works best for an outdoor lawn in November?"
     * "What should my sound and photography timeline look like?"
     The assistant calculates per-guest metrics and provides mathematical and
     logistical recommendations in real time.

3. Granular Section-by-Section Refinement (src/services/aiService.ts -> refineSection)
   - Where: Located inside the Concept, Catering, Entertainment, and Contingency
     cards in Event Overview (src/components/event/EventOverview.tsx).
   - What it does: Allows organizers to prompt the AI to regenerate or pivot a single
     aspect (e.g., "Make catering pure veg royal Rajasthani" or "Suggest budget-friendly
     entertainment") without wiping out or modifying the rest of their budget or timeline.

4. Smart Financial Cost-Saving Optimization (src/services/aiService.ts -> costSavingTips)
   - Where: Featured prominently inside the Budget Planner (src/components/budget/BudgetPlanner.tsx).
   - What it does: Analyzes current planned expenditures against the total budget
     and outputs actionable cost-reduction strategies with exact estimated INR savings
     (e.g., "Optimize guest RSVP 5 days prior to reduce food buffer from 15% to 5% —
     estimated savings ₹18,000").
   - Actionability: Includes a 1-click "Apply Savings" button that automatically
     updates the corresponding expense line item and updates the financial health score.

5. Personalized Creative Studio Asset Generation (src/services/aiService.ts -> generateStarterCreatives)
   - Where: Inside Creative Studio (src/components/creative/CreativeStudio.tsx).
   - What it does: Synthesizes high-conversion, ready-to-use digital assets:
     * WhatsApp Invitations with custom emoji formatting, dress codes, and RSVP links.
     * Instagram Reels captions and trending hashtags tailored to the event vibe.
     * Host and Emcee welcome speeches with tone modulation (Student Hype,
       Royal Imperial, Heartwarming Family, or Corporate Formal).
     * Catchy event monikers and day-of hourly schedules.
   - Features: One-click clipboard copy with immediate visual feedback.
